# 0.2.1

This patch fixes query execution, transaction recovery, and graph interchange
issues found in two code audits.

- Cancelled managed writes roll back automatic transactions. A subsequent
  successful write remains durable, and explicit transactions retain prior writes.
- DuckDB scan cleanup retains object ownership across cache invalidation and
  transaction recovery. Temporary scan aliases cannot replace caller-owned views.
- Deep execution plans and long traversals preserve query semantics without
  implicit hop ceilings. The Rust `RelBackendOptions::varlen_recursive_ceiling`
  field has been removed; bounds explicitly written in queries still apply.
- Deep Gremlin parsing uses guarded stack growth, and parser tree cleanup is
  iterative. Strategy configuration and `hasKey(P)` apply their parsed semantics.
- Negated label conjunctions retain valid candidates, including secondary labels.
- GraphSON imports normalize accepted encodings of typed element IDs and reject
  duplicate decoded IDs before applying mutations.
- SPARQL construction preserves literal identity, ontology properties resolve
  across classes, and PostgreSQL exchange decoding handles large Arrow variants.
- Permission scopes support query-backed mappings. Numeric equivalence and
  mixed property types retain their language-specific behavior.
- macOS release jobs use the macOS 26 ARM and Intel runners. Existing artifact
  reuse, Windows support, and the macOS deployment target are preserved.

The audit validation passed 339 local tests and 6,382 optimized compatibility
cases, with 151 unchanged RDF exclusions and no failures. Compiler checks and
release builds reported no warnings. Release publication additionally requires
the coordinated cross-client checks and verified platform artifacts described
in `scripts/release/README.md`.
