# RDF mapping semantics

RDF mappings declare how table values become subjects, predicates, objects, and
named graphs. Templates construct IRIs from keys; literal mappings preserve value
and datatype meaning. Typed term columns distinguish IRIs, blank nodes, and literals.

These are mappings over application data, not a new reasoning engine. The extension
preserves the existing SPARQL scope. See [SPARQL](sparql.md) and [RDF storage](rdf.md).
