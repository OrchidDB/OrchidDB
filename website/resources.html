Resources

Guides, examples, and recorded results for understanding OrchidDB.

Learn and build

  • Quickstart: create a graph and run your first query.
  • Rust API: embed the engine in an application.
  • CLI reference: query a graph from the command line.
  • Query recipes: examples to adapt to your data.

Understand the engine

  • Execution and plans: graph planning, SQL execution, and Arrow results.
  • Mapping reference: connect graph concepts to tables and columns.
  • Runnable examples: source files in the repository.

Inspect the evidence

The conformance guide explains the upstream test suites and links to the full comparison report, per-scenario outcomes, and downloadable evidence. Results describe the checked-in runs and their scope.
