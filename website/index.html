About the Project

OrchidDB brings graph queries to your data lake. Map the tables you already own to nodes, relationships, and properties. An embedded Rust engine plans and executes the query in your application, using DuckDB to access the mapped data.

Rust

The three query languages share Graph IR and SQL IR. DuckDB reads mapped tables; DataFusion handles the remaining execution stages. Iceberg access uses the DuckDB extension and your catalog configuration. Query results return as Arrow record batches.

OrchidDB is a prototype. Read the documentation and recorded conformance results for the current behavior and limitations.

Install OrchidDB

Choose your client and get started with OrchidDB.

Command line

Download the native CLI from GitHub Releases.

curl -fsSL https://install.orchiddb.com | bash

macOS (Apple Silicon / Intel) · Linux (x86_64, glibc 2.35+). Installs into ~/.local/bin; verifies SHA-256 checksums. Windows: use the ZIP download from GitHub Releases.

Binary downloads activate with the first published release. Until then, install from source. All releases and direct downloads →

Then run your first query:

orchiddb --query 'RETURN 1 AS value'

Rust library

Add OrchidDB to your Cargo project from source.

cargo add orchiddb --git https://github.com/OrchidDB/OrchidDB

The default build includes DuckDB. See the Rust guide for runtime and Arrow dependencies.
