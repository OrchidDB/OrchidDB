An embedded graph engine for your data lake.

Crabgraph is an embedded graph engine for your existing data lake. Built in Rust with DataFusion, Apache Arrow, and DuckDB, it lets you query your tables with Cypher, Gremlin, and SPARQL.

Mapped graphs

Define a graph over your schema.

A node label maps to a table or view. Columns supply identifiers and properties. Edge mappings specify the source and destination of each relationship.

For writable mappings, inserts, updates, and deletes target the tables and columns you specify. Your schema defines where the data belongs.

Architecture

From graph query to execution plan.

Each language produces Graph IR, which lowers to a SQL IR DAG. DuckDB executes SQL regions; DataFusion executes the remaining stages and passes results between them.

Language semantics

Graph IR records path rules, duplicate rows, optional matches, missing properties, and traverser state.

SQL execution

The planner groups scans, filters, joins, and aggregates into SQL regions that DuckDB can optimize together.

Table mappings

Mappings connect graph labels, relationships, and properties to your tables, views, and columns.

Shared execution

DataFusion schedules the DAG, including operations outside SQL regions. Dependent stages consume their results.

Execution

Built with DuckDB, DataFusion, and Arrow.

DuckDB runs the generated SQL against your mapped data. DataFusion provides logical plans and the execution stages around that SQL. Apache Arrow carries tabular results between stages.

See the execution guide for planning details and the conformance comparison for results from the upstream language suites.
