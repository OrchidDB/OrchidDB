Crabgraph

An embedded graph query engine written in Rust

Query connected data with Cypher, Gremlin, and SPARQL. Crabgraph maps nodes and relationships to your tables and runs graph queries using DuckDB and DataFusion.

About the Project

Crabgraph is an embedded graph engine. Use it from a Rust application or the command line to explore relationships in your data. You can create a graph managed by Crabgraph or map a graph onto existing relational tables and views.

Rust

The three query languages share a planning pipeline. Relational parts of a query become SQL; DataFusion executes the remaining stages. Results are returned as Arrow record batches.

Crabgraph is a prototype. Read the documentation and recorded conformance results for the current behavior and limitations.
