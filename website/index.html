Who does Alice follow? Write the question as a graph traversal. Your mapped tables supply the answer.

Build this graph mapping →

Cypher query

MATCH (p:Person)-[:FOLLOWS]->(friend:Person)
WHERE p.name = 'alice'
RETURN DISTINCT friend.name AS name
ORDER BY name

Gremlin traversal

g.V().hasLabel('Person')
  .has('name', 'alice')
  .out('FOLLOWS').values('name')
  .dedup().order()

SPARQL with a mapped vocabulary

PREFIX ex: <https://example.com/>
SELECT DISTINCT ?name WHERE {
  ?p a ex:Person ; ex:name "alice" ; ex:follows ?friend .
  ?friend ex:name ?name .
} ORDER BY ?name

↓ Equivalent SQL over your tables

SELECT DISTINCT friend.name
FROM users p
JOIN follows f ON f.src = p.id
JOIN users friend ON friend.id = f.dst
WHERE p.name = 'alice'
ORDER BY friend.name
