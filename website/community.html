Community

Crabgraph is an early project. Use GitHub to ask questions, report problems, and discuss proposed changes.

Get involved

  • Browse the source and try the quickstart.
  • Open an issue with a small query, your environment, and the result you expected.
  • Review or propose a change. For larger changes, start with an issue to discuss the approach.
  • Read the current license before using or redistributing the code. The repository currently uses a GPL-3.0-only license.
