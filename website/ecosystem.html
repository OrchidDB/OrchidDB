Ecosystem

OrchidDB connects graph query languages to the Rust data ecosystem.

Built with

  • Rust: the implementation language and library interface.
  • DuckDB: the default SQL execution engine.
  • Apache DataFusion: execution of the remaining query stages.
  • Apache Arrow: columnar result batches passed between stages and returned to callers.

Query languages

  • Cypher: describe patterns of nodes and relationships.
  • Gremlin: describe traversals through a graph.
  • SPARQL: query through an ontology mapping, or use the separate mapped RDF dataset interface.

Your data

Use managed graphs for graph persistence or mapped graphs for existing tables. The SQL sources guide covers views and external data exposed through DuckDB.
